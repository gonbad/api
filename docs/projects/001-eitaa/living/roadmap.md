# 001-eitaa Roadmap

Deferred features, improvements, and secondary use cases for future versions:

- [ ] **Multi-Account Proxy Routing**: Assign dedicated outbound HTTP/SOCKS5 proxies per session to prevent IP blocking.
- [ ] **Voice & Audio Transcoding**: Support sending and converting voice messages with opus/ogg waveform headers.
- [ ] **Channel & Group Administration**: Manage member lists, channel posts, and administrative actions.
- [ ] **Rate Limiting & Queue Resilience**: Redis-backed outbound rate limiter to respect platform burst limits.
