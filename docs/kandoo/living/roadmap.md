# Kandoo Shared Roadmap

Shared capabilities, candidate platform bridges, and future infrastructure enhancements across all projects.

## Platform Bridges
- [ ] **001-eitaa**: Eitaa messenger REST/OpenAPI gateway with multi-session management and OTP login.
- [ ] **WhatsApp Bridge**: WAHA-compatible or Playwright-based WhatsApp session gateway.
- [ ] **Bale Bridge**: Bale messenger bot & user-client HTTP gateway.
- [ ] **Rubika Bridge**: Rubika web/protocol API bridge.

## Shared Infrastructure & Monetization
- [ ] **Centralized Auth & Billing**: Shared session authorization service and paid session provisioning (banked from intake).
- [ ] **Centralized Webhook Hub**: Unified webhook dispatching service across multiple active platform bridges.
